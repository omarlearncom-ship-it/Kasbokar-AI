# کاربار AI — نسخه اولیه

## امکانات این نسخه
- رابط فارسی با انتخاب کشور و زبان
- چت با API سمت سرور (Groq اختیاری)
- انتخاب دستهٔ کسب‌وکار
- دکمه نصب PWA، manifest، آیکون و service worker
- ساختار آماده برای توسعهٔ مدیریت، سهمیه‌ها و ابزارهای دیگر

## استقرار
1. محتویات ZIP را در یک مخزن GitHub بارگذاری کن.
2. در Render، New > Blueprint و مخزن را انتخاب کن تا `render.yaml` خوانده شود.
3. در سرویس `karbar-ai-api` متغیر محرمانهٔ `GROQ_API_KEY` را تنظیم کن.
4. در سرویس Static Site متغیر `API_BASE_URL` در `frontend/app.js` را پس از ساخته‌شدن API به آدرس عمومی API تغییر بده، سپس commit/push کن.
5. برای نصب PWA باید سایت با HTTPS ارائه شود؛ دامنهٔ رایگان `onrender.com` نیز می‌تواند کافی باشد و دامنهٔ اختصاصی الزامی نیست.

## مهم
این یک MVP اولیه است، نه محصول کامل تولیدی. ورود واقعی، PostgreSQL، سهمیهٔ امن سمت سرور، تولید تصویر/موسیقی/ویدئو، پرداخت، OAuth شبکه‌های اجتماعی و انتشار خودکار وب‌سایت هنوز باید جداگانه ساخته شوند. هیچ کلید API را در فرانت‌اند یا مخزن عمومی نگذار.
